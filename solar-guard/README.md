# ⚡ Solar Guard — เฝ้าระวังการใช้ไฟจากโซลาร์ แล้วแจ้งเตือนพนักงานให้ไปลดโหลด

ระบบเล็ก ๆ ที่คอยดูว่า **ตอนนี้โรงงานกำลังซื้อไฟจากการไฟฟ้าอยู่กี่ kW** ถ้าโซลาร์เอาไม่อยู่จนไฟหลวงเข้ามาเยอะเกินเกณฑ์ จะแจ้งเตือนพนักงานพร้อม **บอกเลยว่าให้ไปปิดอะไรบ้าง** เช่น ปิดแอร์ชั้น 2 เลื่อนเดินคอมเพรสเซอร์ ฯลฯ

- 🏭 ดึงข้อมูลจาก **Huawei FusionSolar** (Northbound API)
- ☁️ รันบน **Cloudflare Workers** — ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องรัน Node ค้างไว้บนเครื่องไหนทั้งนั้น
- 💬 แจ้งเตือนทาง **Telegram** (ฟรีไม่จำกัด) + **อีเมล** (เฉพาะเรื่องใหญ่)
- 📺 มี **หน้าจอติดผนัง** ไฟสามสี พร้อมเสียงไซเรนจากลำโพงเครื่องนั้นเลย
- 🚨 ต่อ **ไฟหมุนจริง** ทีหลังได้ผ่าน `/api/state` (ดู [`docs/SIREN.md`](docs/SIREN.md))

> 📖 **อ่าน [`docs/ALERTING.md`](docs/ALERTING.md) ก่อนใช้งานจริง** — ตรงนั้นอธิบายว่าทำไมถึงเตือนแบบนี้ ตั้งเกณฑ์ยังไงไม่ให้พนักงานเบื่อจนเลิกสนใจ และเรื่องที่โค้ดช่วยไม่ได้แต่สำคัญกว่าโค้ด

## ค่าใช้จ่าย

| อย่าง | ราคา |
|---|---|
| Cloudflare Workers (แพ็กฟรี) | **0 บาท** — ระบบนี้ใช้ ~290 ครั้ง/วัน จากโควตา 100,000 |
| Cloudflare KV (แพ็กฟรี) | **0 บาท** — ใช้เขียน ~290 ครั้ง/วัน จากโควตา 1,000 |
| Telegram Bot | **0 บาท** ไม่จำกัดข้อความ |
| อีเมล (Resend / Brevo แพ็กฟรี) | **0 บาท** — Resend 3,000 ฉบับ/เดือน หรือ Brevo 300 ฉบับ/วัน |
| หน้าจอติดผนัง | 0 บาท ถ้าใช้คอม/แท็บเล็ตเก่าที่มีอยู่ |
| ไฟหมุน + ESP32 (ทำทีหลัง) | ~700–1,200 บาท ครั้งเดียว |

**รวม 0 บาท/เดือน** ทุกอย่างอยู่ในแพ็กฟรีจริง ๆ ไม่ต้องผูกบัตร

## สิ่งที่ต้องมีก่อนเริ่ม

1. **บัญชี Northbound API ของ FusionSolar** — ขอจากดีลเลอร์/ผู้ติดตั้งระบบโซลาร์ (คนละตัวกับ user ที่ใช้ล็อกอินแอพ) จะได้มาเป็นคู่ `username` + `system code`
2. **Smart Power Sensor (มิเตอร์) ที่จุดเชื่อมต่อการไฟฟ้า** — ⚠️ **ข้อนี้จำเป็น** ถ้าระบบมีแค่อินเวอร์เตอร์ไม่มีมิเตอร์ จะรู้แค่ว่าผลิตได้กี่ kW แต่ไม่รู้ว่าซื้อไฟเข้ามากี่ kW ซึ่งเป็นตัวเลขหลักที่ระบบนี้ใช้ (เช็คได้ในแอพ FusionSolar ว่าหน้า Device มี "Power Sensor" / "Meter" อยู่ไหม)
3. **บัญชี Cloudflare** (ฟรี) และ **บัญชี Telegram**

## ติดตั้ง

### 1) เตรียม Cloudflare

```bash
cd solar-guard
npx wrangler login                          # เปิดเบราว์เซอร์ให้ล็อกอิน
npx wrangler kv namespace create SOLAR_KV   # จะได้ id ยาว ๆ กลับมา
```

เอา `id` ที่ได้ไปใส่ใน `wrangler.toml` ตรงบรรทัด `ใส่_KV_NAMESPACE_ID_ตรงนี้`

### 2) สร้างบอท Telegram

1. แชทกับ [@BotFather](https://t.me/BotFather) → พิมพ์ `/newbot` → ตั้งชื่อ → จะได้ **token**
2. สร้างกลุ่ม Telegram ของพนักงาน แล้ว **เชิญบอทเข้ากลุ่ม**
3. หา chat id ของกลุ่ม: พิมพ์อะไรก็ได้ในกลุ่ม 1 ข้อความ แล้วเปิดลิงก์นี้ในเบราว์เซอร์

   `https://api.telegram.org/bot<TOKEN>/getUpdates`

   มองหา `"chat":{"id":-1001234567890` — เลขติดลบนั่นคือ **chat id ของกลุ่ม**

### 3) ใส่ค่าลับ

```bash
npx wrangler secret put FUSION_USER            # username ของ Northbound API
npx wrangler secret put FUSION_SYSTEM_CODE     # system code
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID       # เลขติดลบของกลุ่ม
npx wrangler secret put DASHBOARD_TOKEN        # ตั้งรหัสอะไรก็ได้ ไว้กันคนนอกเปิดหน้าจอ

# ไม่บังคับ
npx wrangler secret put TELEGRAM_BOSS_CHAT_ID  # chat id ของหัวหน้า ไว้ตามเวลาไม่มีใครรับเรื่อง
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
npx wrangler secret put RESEND_API_KEY         # หรือ BREVO_API_KEY
npx wrangler secret put MAIL_FROM              # เช่น solar@yourdomain.com
npx wrangler secret put MAIL_TO                # หลายคนคั่นด้วย ,
```

### 4) ปรับค่าใน `wrangler.toml`

อย่างน้อยต้องแก้ 3 อย่างนี้:

- `SITE_NAME` — ชื่อโรงงาน
- `SYSTEM_KWP` — ขนาดระบบโซลาร์ที่ติดตั้ง
- `LOAD_SHED_LIST` — **รายการอุปกรณ์ที่ให้พนักงานไปปิด พร้อมตัวเลข kW จริงและชื่อคนรับผิดชอบ** (สำคัญที่สุด ควรใช้แคลมป์มิเตอร์วัดจริงสักครั้ง)

ส่วนเกณฑ์ `WARN_IMPORT_KW` / `CRIT_IMPORT_KW` **อย่าเพิ่งตั้งจริง** — ดูขั้นตอนจูนในหัวข้อถัดไป

### 5) Deploy

```bash
npx wrangler deploy
```

จะได้ URL ประมาณ `https://solar-guard.<ชื่อบัญชี>.workers.dev`

### 6) เช็คว่าใช้ได้

```bash
# ทดสอบส่งข้อความเข้ากลุ่ม
curl "https://solar-guard.xxxx.workers.dev/api/test-alert?k=DASHBOARD_TOKEN"

# ลองดึงข้อมูลจาก FusionSolar 1 รอบ
curl "https://solar-guard.xxxx.workers.dev/api/poll?k=DASHBOARD_TOKEN"

# เปิดใช้คำสั่ง /ack /status /mute ในกลุ่ม (เรียกครั้งเดียวพอ)
curl "https://solar-guard.xxxx.workers.dev/api/setup-webhook?k=DASHBOARD_TOKEN"
```

### 7) ⚠️ ตรวจทิศทางมิเตอร์ (ข้ามไม่ได้)

**ตอนกลางคืน** (ไม่มีแดด ต้องซื้อไฟจากการไฟฟ้าแน่นอน) เรียก:

```bash
curl "https://solar-guard.xxxx.workers.dev/api/poll?k=DASHBOARD_TOKEN"
```

ดูค่า `sample.grid`

- ถ้าเป็น **บวก** → ถูกแล้ว ไม่ต้องแก้อะไร
- ถ้าเป็น **ลบ** → มิเตอร์นับกลับทาง ให้แก้ `METER_SIGN = "-1"` ใน `wrangler.toml` แล้ว `npx wrangler deploy` ใหม่

ถ้าตั้งผิด ระบบจะเตือนตอนที่แดดดีที่สุด ซึ่งตรงข้ามกับที่ควรจะเป็น

### 8) เปิดหน้าจอติดผนัง

`https://solar-guard.xxxx.workers.dev/?k=DASHBOARD_TOKEN`

เอาคอม/แท็บเล็ตเก่าเปิดค้างไว้หน้าออฟฟิศ กดปุ่ม `🔇 เปิดเสียงเตือน` ครั้งเดียว แล้วเวลาสถานะแดงจะมีเสียงไซเรนออกลำโพงเครื่องนั้น (รายละเอียดใน [`docs/SIREN.md`](docs/SIREN.md))

## จูนเกณฑ์ยังไงไม่ให้พนักงานเบื่อ

**อย่าเดาตัวเลข** — วิธีที่ใช้ได้จริง:

1. **สัปดาห์ 1–2**: ตั้ง `WARN_IMPORT_KW = "9999"` ไว้ก่อน ระบบจะเก็บข้อมูลอย่างเดียวโดยไม่เตือนเลย
2. เปิด dashboard ดูกราฟ ว่าปกติแล้วโรงงานซื้อไฟอยู่กี่ kW ช่วงไหนพุ่ง
3. **ตั้งเหลือง** = ค่าที่เกินประมาณ 20% ของเวลาทำงาน / **ตั้งแดง** = ค่าที่เกินแค่ 5%
4. **สัปดาห์ที่ 4**: นับจำนวนข้อความต่อวัน — ถ้าเกิน 3 ครั้ง/วัน ให้ขยับเกณฑ์ขึ้น อย่าปล่อยให้คนชิน

เหตุผลเต็ม ๆ อยู่ใน [`docs/ALERTING.md`](docs/ALERTING.md) หัวข้อ 3 และ 11

## ข้อจำกัดที่ควรรู้

- **FusionSolar จำกัดความถี่การเรียก** — ห้ามตั้ง cron ถี่กว่า 5 นาที ไม่งั้นจะโดนตอบ `failCode 407` แล้วข้อมูลจะขาด (โค้ดจัดการให้แล้วโดยข้ามรอบนั้นไป ไม่ยิงซ้ำ)
- **ข้อมูลช้าประมาณ 5–10 นาที** — FusionSolar เองก็อัปเดตข้อมูลเป็นรอบ ไม่ใช่ real-time เพราะฉะนั้นระบบนี้เหมาะกับ "โหลดที่ค้างอยู่นาน ๆ" เช่นแอร์ ไม่เหมาะกับการจับ spike สั้น ๆ ระดับวินาที
- **ต้องมีมิเตอร์** ถ้าไม่มี Smart Power Sensor จะใช้ไม่ได้ (ดูหัวข้อ "สิ่งที่ต้องมีก่อนเริ่ม")
- **ตัวเลข kW ในรายการอุปกรณ์เป็นค่าที่กรอกเอง** ระบบไม่ได้วัดจริงว่าปิดแอร์แล้วลดได้เท่าไหร่ ควรวัดด้วยแคลมป์มิเตอร์ครั้งเดียวแล้วกรอกให้ตรง

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| `/api/poll` ตอบ `ล็อกอิน FusionSolar ไม่สำเร็จ` | ใช้ user ของแอพแทน Northbound API / เลือก `FUSION_BASE` ผิดโซน (ไทยมักเป็น `intl`) |
| `ไม่พบมิเตอร์ (Smart Power Sensor)` | ระบบไม่ได้ติดมิเตอร์ หรือมิเตอร์ออฟไลน์อยู่ |
| เตือนตอนแดดดี ๆ | `METER_SIGN` กลับทาง → ทำขั้นตอนที่ 7 |
| เตือนถี่มาก | เกณฑ์ต่ำไป → จูนตามหัวข้อข้างบน |
| ไม่มีข้อความเข้ากลุ่มเลย | ยังไม่ได้เชิญบอทเข้ากลุ่ม / ใช้ chat id ผิด (ของกลุ่มต้องเป็นเลขติดลบ) |
| `/ack` ไม่ทำงาน | ยังไม่ได้เรียก `/api/setup-webhook` |
| จอไม่มีเสียง | เบราว์เซอร์ต้องให้คนกดปุ่ม `เปิดเสียงเตือน` ก่อน 1 ครั้ง |

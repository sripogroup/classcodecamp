พ่อเต้ยสั่งย้ายแอพ solar-guard ออกจาก repo `classcodecamp` เพราะวางผิดหลักการณ์ของร้าน
(แบบแผนคือ 1 แอพ = 1 โฟลเดอร์ `app <port> <ชื่องาน>` ที่ระดับ `C:\Users\USER\claude projects`
พร้อม git repo ของตัวเอง แต่แอพนี้ถูกสร้างซ้อนอยู่ใน repo ของคอร์สเรียน)

- ที่เดิม: `C:\Users\USER\claude projects\classcodecamp\solar-guard`
- ที่ใหม่: `C:\Users\USER\claude projects\app 8787 เฝ้าระวังไฟโซลาร์`
- ชื่อใช้พอร์ต 8787 เพราะเป็นพอร์ตจริงของแอพ (`server/config-local.js` → `LOCAL_PORT` ค่าเริ่มต้น 8787)

## ⚠️ แอพนี้มี autostart อยู่ 2 จุด — ต้องแก้ทั้งคู่หลังย้าย

1. **watchdog กลาง** `C:\SripoServer\server-watchdog.ps1` ตาราง `$apps` บรรทัดสุดท้าย
   `@{port=8787; dir='classcodecamp\solar-guard'; entry='server\server.js'}`
   — ฟังก์ชัน `Resolve-AppDir` หาโฟลเดอร์ `app <port> *` ที่ระดับบนสุดก่อนเป็นอันดับแรก
   **หลังย้ายมันจะเจอเองอัตโนมัติ** แต่ควรแก้ `dir` ให้ตรงความจริงด้วย (สำรองไฟล์ก่อนเสมอ)

2. **`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\sripo-app-8787.vbs`**
   ไฟล์เป็น **UTF-16LE** ข้างในฮาร์ดโค้ด path เก่าไว้:
   `sh.CurrentDirectory = "C:\Users\USER\claude projects\classcodecamp\solar-guard"`
   **ต้องแก้เป็น path ใหม่** ไม่งั้นรอบล็อกอินหน้าแอพจะไม่ขึ้น

- [x] ปิด server + สร้าง `C:\SripoServer\pause-8787.flag` กัน watchdog เปิดซ้ำ แล้วย้ายโฟลเดอร์ (พ่อเต้ยรันเอง เพราะ session เก่าล็อกโฟลเดอร์อยู่)

## ที่ยังเหลือ — ทำต่อได้เลย

1. **แก้ 2 จุด autostart ข้างบน** ให้ชี้ที่ใหม่ (สำรองไฟล์ก่อนแก้ทั้งคู่)

2. **สร้าง repo ของตัวเอง** ที่โฟลเดอร์ใหม่ — `git init` แล้ว commit แรกให้ครบทั้งแอพ
   (มี `.gitignore` อยู่แล้ว ตรวจว่ากัน `node_modules/`, `.dev.vars`, `.wrangler/`, `data/*.db` จริง —
   **สำคัญ: `.dev.vars` มี INGEST_TOKEN กับ DASHBOARD_TOKEN ห้ามหลุดขึ้น git**)

3. **ลบ solar-guard ออกจาก repo classcodecamp** — พ่อเต้ยสั่งว่า **"ลบในคอมมิตใหม่พอ" ไม่ต้องล้างประวัติ**
   ทำที่ `C:\Users\USER\claude projects\classcodecamp` บน branch `claude/solar-power-monitoring-app-bhocmp`

4. **แก้ path ใน Task Scheduler 2 ตัว** (ทั้งคู่ **Disabled** อยู่ ให้คง Disabled ไว้เหมือนเดิม)
   - `Solar Guard FusionSolar Reader` → `local-reader\FusionWebReader.ps1`
   - `Solar Guard Modbus Reader` → `local-reader\ModbusReader.ps1`

   > 2 ตัวนี้ผิดกติกาของร้าน (ต้องใช้ watchdog กลาง ไม่ตั้ง Task แยก) แต่ถูก disable ไว้
   > ควรถามพ่อเต้ยว่าจะเลิกใช้ไปเลยไหม

5. **กันไม่ให้ server รันซ้อนกันหลายตัว** — ตอนจะย้ายพบว่ามี node รันพร้อมกัน 2 instance
   (PID 27436 กับ 25708) เขียน `data/solar-guard.db` ไฟล์เดียวกัน ควรใส่ตัวกันซ้ำ (single-instance lock)
   ที่ `server/server.js`

6. **ลบ `C:\SripoServer\pause-8787.flag`** แล้วรอ 1 นาที ให้ watchdog เปิด server เอง
   จากนั้นเปิด `http://localhost:8787/?k=<DASHBOARD_TOKEN>` ดูว่าหน้าจอขึ้นจริง และรัน `npm test` (ควรผ่าน 112 ข้อ)

7. **ลบไฟล์นี้ทิ้ง** เมื่อทำครบทุกข้อแล้ว
